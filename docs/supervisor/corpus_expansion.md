# 200페이지 문서 확장과 근거 관리

## 문서 구성

기존 문서의 사용 페이지는 161페이지였습니다. 아래 세 문서를 추가하여 총 17개 문서, 사용 페이지 200페이지로 구성했습니다. 전체 인덱스는 255개 청크입니다. 기존 manifest는 비교와 회귀 검증을 위해 유지하고, 기본 실행은 `manifest.expanded.csv`로 만든 `index-expanded`를 사용합니다.

| 문서 | 원문 / 사용 페이지 | 확인한 근거 |
|---|---|---|
| Sensors 2025, 25, 940 | 18 / 18페이지입니다. | p.1에서 DOI, 날짜, 에이딘 소속 저자를 확인했습니다. p.14~15에서 시험 조건과 측정 오차를 확인했습니다. |
| BMW Group 공식 보도자료, 2026-02-27 | 7 / 7페이지입니다. | p.4에서 Figure 02의 현장 운영량과 고객 확인을 확인했습니다. |
| AIDIN Robotics 공식 WRC 회사·제품 자료 | 17 / 14페이지입니다. | p.3~16의 제품·센서·그리퍼·로봇핸드 사양을 사용했습니다. 표지·회사 소개·연락처는 제외했습니다. |

원문은 manifest에 URL, SHA256, 전체 페이지 수와 선택 페이지를 기록했습니다. 구조화한 값은 `data/evidence/tech/*_expanded.json`에 있으며, 각 기록을 PDF 페이지와 연결했습니다. 공식 웹의 ALICE 시연 목록은 WEB 출처로 추가했습니다. 웹 목록은 정량 성공률이나 독립적인 현장 검증을 뜻하지 않습니다.

## 해석과 인정 범위

- 에이딘 논문 DOI는 `10.3390/s25030940`이며 2025-02-04 발행입니다. 에이딘 소속 저자와 기업 설립 이후 논문이라는 조건이 확인되어 기존 K1에 논문 1편으로 인정했습니다.
- 센서 논문은 15N·75N·mm의 측정 범위와 기준 센서 대비 상대 오차를 보고합니다. 정확도·오차는 로봇 조작 성공률과 다른 지표입니다. 원래 K2의 성공 횟수·전체 시도 수를 만들어 넣지 않았습니다.
- BMW 자료는 3만 대 이상의 X3 생산 지원, 9만 개 이상의 부품 이동, 약 1,250시간의 운영을 고객이 확인한 기록입니다. 동일한 Spartanburg 현장은 반복 기사에 나와도 1개 현장으로 계산합니다. 공개 일자는 실제 완료 일자와 구분합니다.
- 제조사 사양과 시연은 초기 단계 비교 기준에서만 제한적으로 인정합니다. 제품이 41자유도라는 사실만으로 실증 성공이나 제조 현장 배치를 인정하지 않습니다.
- LLM이 Top 5 문서만 보고 작성한 전체 조회 완료 주장은 수용하지 않습니다. 완전 조회가 입증되지 않으면 자료 미확보를 0건으로 바꾸지 않습니다.

추가 자료는 기업 발표, 학술 출판물, 고객 확인 자료로 구분합니다. 학술 출판물에 기업 저자가 참여했다는 사실은 확인할 수 있지만, 해당 연구의 모든 성능을 외부 기관이 독립 재현했다고 해석하지는 않습니다.

## 검색 확인

논문 DOI·저자 소속, 센서 시험 오차, BMW 운영량에 대한 세 가지 검색에서 각 목표 문서를 Top 5에서 확인했습니다. 이는 추가 문서의 검색 가능성을 확인한 점검이며 전체 검색 품질을 대표하는 통계는 아닙니다. 조회 결과는 `evidence/expanded-retrieval-check.json`에 기록했습니다.

## 기존 자료의 한계

이번 추가 수집은 기술 논문과 고객 확인 자료를 중심으로 수행했습니다. 기존 저장 자료의 투자 라운드·고용·재무·특허 수치를 모두 외부 원천에서 다시 검증한 것은 아닙니다. 현재 점수는 저장 자료와 새로 확인한 기술 근거를 적용한 계산 결과입니다. 실제 투자 판단에 사용하려면 각 원천의 식별자·조회 날짜·금액·등록 상태를 추가 확인해야 합니다.
