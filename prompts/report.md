# 보고서 생성 원칙

새 검색을 수행하지 않고 archive가 확정한 전체 후보 EvaluationRecord만 사용한다.
후보 누락·중복, 미등록 source_id, 미완료 채점은 오류로 중단한다.
SUMMARY에는 후보별 추천·보류와 저장된 총점을 그대로 표시한다. 채점하거나 판정을 바꾸지 않는다.
자료 없음은 0이 아니며, 분석 생략 점수 None은 '미산정'으로 표시한다.
근거 없는 사업 설명·미래 수익률·투자 집행·현장 사용 승인을 추가하지 않는다.
모든 수치·조건·근거 상태와 미확인 항목을 State에서 가져온다.
첫 페이지 SUMMARY는 반 페이지 이내, 전체는 5쪽 이내, 마지막은 REFERENCE다.
본문에 실제 인용한 source_id만 REFERENCE와 결과 JSON에 포함한다.
페이지에 들어가지 않는 입력은 조용히 자르지 않고 명시적 오류로 반환한다.
